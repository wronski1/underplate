# Underplate — Website Starter

Underplate helps you discover local restaurant specials hiding in plain sight.

## Publish on Vercel
1. Upload `index.html`, `config.js`, `manifest.webmanifest`, `sw.js`, and the `icons` folder to the root of your GitHub `underplate` repository.
2. In Vercel, import `wronski1/underplate`. Choose **Other**, root `./`, leave build command blank and deploy.
3. Once deployment succeeds, add `getunderplate.com` under Project → Settings → Domains. Follow Vercel's displayed DNS instructions in Namecheap.

## Important
- Current listings are **research previews, not verified by restaurants**. They are clearly labeled as such. Do not market them as confirmed specials.
- Nearby uses browser location permission and approximate straight-line distances.
- No database is configured yet. The preview works as a standalone static site.
- This is an early prototype, not a commercial production launch. Review hosting terms, trademark clearance, privacy policy, and data accuracy before launch.
- The production database and private admin dashboard will be added separately after the website is live.
